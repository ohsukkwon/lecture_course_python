# Python Programming Fundamentals - 12일 완성 과정
## 파이썬 기본 교육 커리큘럼

---

## 교육 과정 개요

본 교육 과정은 프로그래밍 입문자를 대상으로 파이썬의 기초부터 실무 활용까지 체계적으로 학습하는 **12일 완성 과정**입니다.

---

## 학습 목표

- 파이썬 프로그래밍 기초 개념 이해 및 활용
- 실무에 활용 가능한 코딩 능력 배양
- 객체지향 프로그래밍 개념 이해 및 적용
- 외부 라이브러리를 활용한 실전 프로젝트 개발 능력
- 독립적으로 프로그램을 설계하고 구현하는 능력 함양

---

## 대상 학습자

- 프로그래밍을 처음 시작하는 입문자
- 다른 언어 경험은 있지만 파이썬을 배우고자 하는 학습자
- 데이터 분석, 웹 개발 등을 위해 파이썬 기초가 필요한 학습자

---

## 교육 특징

1. **체계적인 단계별 학습**: 기초부터 실무까지 단계적으로 학습
2. **풍부한 실습 예제**: 각 개념마다 다양한 실습 코드 제공
3. **실전 프로젝트**: 학습한 내용을 활용한 실전 프로젝트 진행
4. **한글/영어 주석**: 이해를 돕는 상세한 이중 언어 주석

## 일차별 커리큘럼

### 1일차: 파이썬 소개 및 환경 설정
- 파이썬 소개 및 특징
- 개발 환경 구축 (Python, VS Code, PyCharm)
- 첫 프로그램 작성 및 실행
- 기본 입출력

### 2일차: 기본 문법 - 변수, 자료형, 연산자
- 변수와 자료형 (int, float, str, bool)
- 형 변환 (Type Casting)
- 연산자 (산술, 비교, 논리, 할당, 멤버십)
- 문자열 포맷팅 및 메서드

### 3일차: 제어문 - 조건문과 반복문
- 조건문 (if, elif, else)
- 반복문 (for, while)
- 제어문 (break, continue, pass)
- 중첩 반복문 및 실습

### 4일차: 함수
- 함수 정의 및 호출
- 매개변수와 인자 (위치 인자, 키워드 인자, 가변 인자)
- 반환값 (return)
- 지역 변수와 전역 변수
- 람다 함수

### 5일차: 자료구조 I - 리스트와 튜플
- 리스트 생성 및 접근
- 리스트 메서드 및 연산
- 리스트 컴프리헨션
- 튜플의 특징 및 활용
- 리스트 vs 튜플

### 6일차: 자료구조 II - 딕셔너리와 집합
- 딕셔너리 생성 및 접근
- 딕셔너리 메서드
- 딕셔너리 컴프리헨션
- 집합(Set) 연산 및 메서드
- 자료구조 선택 가이드

### 7일차: 모듈과 패키지
- 모듈의 개념 및 import
- 표준 라이브러리 (math, random, datetime, os, sys)
- 사용자 정의 모듈 만들기
- 패키지 구조 및 __init__.py
- pip를 이용한 외부 패키지 설치

### 8일차: 파일 입출력
- 파일 읽기 (read, readline, readlines)
- 파일 쓰기 (write, writelines)
- with 문을 이용한 파일 처리
- CSV 파일 다루기
- JSON 파일 다루기

### 9일차: 예외 처리 및 디버깅
- 예외(Exception)의 개념
- try-except-else-finally 구문
- 예외 발생시키기 (raise)
- 사용자 정의 예외
- 디버깅 기법 및 로깅

### 10일차: 객체지향 프로그래밍 I - 기초
- 객체지향 프로그래밍의 개념
- 클래스와 객체
- 생성자 (__init__)와 소멸자 (__del__)
- 인스턴스 변수와 메서드
- 클래스 변수와 메서드
- 정적 메서드

### 11일차: 객체지향 프로그래밍 II - 심화
- 상속 (Inheritance)
- 메서드 오버라이딩
- super() 함수
- 다형성 (Polymorphism)
- 캡슐화와 접근 제어
- 매직 메서드 (\_\_str\_\_, \_\_repr\_\_, \_\_add\_\_ 등)

### 12일차: 실전 라이브러리 활용 및 최종 프로젝트
- 정규표현식 (re 모듈)
- 웹 크롤링 (requests, BeautifulSoup)
- 데이터 분석 기초 (pandas, numpy)
- API 활용하기
- 최종 프로젝트 개발 및 발표
